# Тревелон — Сезон Зима 2026-2027

Лендинг-презентація на базі PowerPoint «Сезон 2026-27 Зима» (76 слайдів → 51 повноекранна секція).
Анімаційна механіка в дусі trionn.com, палітра й типографіка — суворо за Travelon Brand Guidelines.

## Керування під час показу

| Клавіша | Дія |
|---|---|
| `→` `↓` `Space` | наступна секція |
| `←` `↑` | попередня |
| `F` | повний екран |
| `Home` / `End` | на початок / у кінець |

Праворуч — рейка секцій (клікабельна), внизу — назва блока, номер і підказка,
зверху — смуга прогресу. Хром накладається режимом `mix-blend-mode: difference`,
тож читається і на білих, і на коралових, і на фото-секціях.

## Анімації (звідки що взято в TRIONN)

| Прийом | Де застосовано |
|---|---|
| Прелоадер з лічильником `000 → 100` і зсувом панелі вгору | старт |
| Маскована поява заголовків по рядках (`overflow:hidden` + `translateY`) | усі `h1` / `h2` |
| Каскадний підйом блоків | картки, списки, таблиці |
| Розкриття зображень кліп-маскою + внутрішній зум | усі фото та скріншоти |
| Паралакс фонових фото при скролі | секції з фото на весь екран |
| Біжучі рядки, один з них контурним шрифтом | напрямки зими й літа |
| Перекат тексту на кнопці при наведенні | телефон, пошта |
| Одометр-лічильники | «21 напрямок», кількість міст вильоту |
| Кастомний курсор, що збільшується над інтерактивом | уся сторінка |

Усе поважає `prefers-reduced-motion` — при вимкненій анімації сторінка просто статична.

## Відповідність брендбуку

| Параметр | Значення |
|---|---|
| Основна палітра | `#FF4C00` корал (172 C), `#171717` чорний (419 C), `#FFFFFF` білий |
| Другорядна | `#FF0138` (185 C), `#FF8000` (2018 C) |
| Світлий фон секцій | `#FFF0EB` — офіційний відтінок коралу 15% |
| Шрифт | Nunito Sans (200–1000, курсиви) — єдиний, як вимагає брендбук |
| Логотип | світла версія, зона Top Left, висота 1.5rem (більше мінімальних 24px) |

Кольорів поза палітрою немає. Градієнти застосовані тільки як затемнення поверх
фотографій (щоб логотип і текст читались) — на самому логотипі градієнтів немає.

## Структура

```

```

Усі зображення витягнуті з вихідної презентації та стиснуті (≈4 МБ разом).

## Публікація на GitHub Pages

Залийте вміст цієї папки в корінь репозиторію, далі
**Settings → Pages → Deploy from a branch → main / (root)**.

## Показ без інтернету

Сторінка тягне Nunito Sans з Google Fonts. Для показу офлайн покладіть `.woff2`
у `assets/fonts/` і замініть `<link>` у `<head>` на локальні `@font-face`.
